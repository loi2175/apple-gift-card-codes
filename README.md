## 兑换之后容易踩的坑

**账单地址和账户里的不一致。** 用国内 Visa 卡在官网买卡时，账单地址必须和 Apple 账户里的「账单寄送地址」完全一样，差一个字都可能触发风控，卡买了却兑不上。

**没设免税州，每月多付一笔税。** 注册在加州的账号，每个月订阅都要多扣 2 美元左右的税。一开始就把账号地址设成免税州，这笔钱能省下来。

**订阅时选错档位。** ChatGPT 的升级页面上方有 Go 和 Plus 两个标签，Go 是另一个产品，没有你要的模型和额度。手滑点错，钱扣了还得再退。

**点订阅弹出「你的购买无法完成」。** 余额明明够，套餐也选对了，就是订不上。有实测有效的办法是换一台 iPhone，用同一个账户重新发起订阅；不行就打 Apple 客服要求转台湾客服，处理完等 48 小时再订。

**以为余额什么都能付。** Apple 账户余额不能用来新开 AppleCare+ 订阅，也不能拿来给别人发礼品卡，这两件事得绑信用卡。

## 常见问题

**卡密能充国区 Apple ID 吗？**
不能。美区卡只能充美区 ID，区域不匹配兑换会直接失败。

**买错了能退吗？**
卡密类商品没有售后期，这是行业通例，账号星球页面也写明了。下单前把面值和账户区域确认好。

**多久能收到卡密？**
账号星球卡密类 24 小时自动发货，多数 5 分钟内到。Apple 官网是邮件发送，进度页写的是 1 小时内，实测十几分钟的居多。用 Gmail 的话去「推广」分类翻一下，容易漏。

**买小了怎么办？**
再补一张小面值的就行，余额是累加的。缺点是两张卡两次税费，损失一点零头，不影响使用。

**带账号版和不带账号版差在哪？**
不带账号版只有 16 位卡密，你得自己有美区 Apple ID。带账号版多发一个已经注册好的美区 ID，拿到改个密码就能登 App Store。差价就是你为省掉注册流程付的钱。
